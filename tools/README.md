# Как обновлять сайт

## Где что лежит

| Что | Файл |
|---|---|
| Статусы, ссылки, палитры, тексты развилки | `config.js` (правится через пульт viaspinosa.art/panel) |
| Проекты Сергея | `spotted/projects.js` |
| CV Сергея, обе версии | `spotted/cv/data.js` |
| Работы, серии, CV Лизы | `strangejell/data.js` |
| Общие функции, подписи интерфейса на английском | `assets/site.js` |

Текст в данных может быть строкой (русский) или `{ ru: "…", en: "…" }`. Если английского нет, показывается русский.
Текст в `[квадратных скобках]` показывается как заглушка, подчёркнутая пунктиром.

## Добавить проект или работу

1. Допишите запись в `spotted/projects.js` или `strangejell/data.js`. У каждой записи свой `id`: латиница, цифры, дефис.
2. Запустите сборку: `node tools/build.mjs`. Она создаст короткий адрес `/spotted/<id>/` или `/strangejell/<id>/`, обновит превью ссылок и sitemap, а страницы удалённых проектов уберёт.

## Картинки

1. Сложите фото и макеты в папку, разложив по подпапкам: `materials/spotted/veranda/01.jpg`.
2. `python3 tools/images.py materials/` — получится `assets/img/spotted/veranda/01-800.webp` и `-1600.webp`, без метаданных и геометки.
3. В данных проекта: `cover: "/assets/img/spotted/veranda/01"` для обложки и
   `images: [{ src: "/assets/img/spotted/veranda/01", ratio: "3:2", cap: "подпись" }]` для галереи.
   Пропорции каждой картинки записаны в `assets/img/manifest.json`.

Сама папка `materials` в репозиторий не попадает, только готовые картинки.

## Аватары

`python3 tools/images.py --avatar фото.jpg --name nab --cx 0.5 --cy 0.42 --size 0.65`
Центр кадра и размер — в долях ширины фото. Результат: `assets/nab.jpg`, на развилке он подключается атрибутом `data-photo="/assets/nab.jpg"`.

## Шоурилы (видео в Cloudflare R2)

Видео не лежат в репозитории: GitHub Pages для них слишком тесный. Они хранятся в Cloudflare R2, на бесплатном тарифе это 10 ГБ и без платы за просмотры.

1. `tools/reel.sh исходник.mov showreel-2025-2026` — получится сжатый `showreel-2025-2026.mp4` (до 1080p, без метаданных, запускается сразу) и постер `.jpg`. Нужен ffmpeg: `brew install ffmpeg`.
2. Загрузите оба файла в бакет R2 (Cloudflare → R2 → бакет → Upload).
3. Ссылки вида `https://media.viaspinosa.art/showreel-2025-2026.mp4` впишите в пульте: «раздел Лизы» → «шоурилы» → url и картинка до запуска. Или в `strangejell/data.js`, поле `showreels`.

Самый свежий по годам шоурил открывается первым, остальные переключаются кнопками с годами.
